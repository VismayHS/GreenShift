## Key decisions so far (and why)

1. **Primary carbon data = GB Carbon Intensity API** (CC BY 4.0, no key, half-hourly, forecast + actual, 17 regions). Electricity Maps free CSVs appear to be sunset for non-academics, so it is optional. See notes/01.
2. **Measure energy with Intel RAPL through Windows' Energy Meter counters**, cross-checked with battery discharge and a calibrated utilisation model. See notes/02.
3. **Workload = TPC-DS-derived Spark SQL jobs**, with data generated by DuckDB's dsdgen port. All 99 queries run on Spark 4.2. See notes/04.
4. **Spark 4.2.0 + portable Temurin JDK 21** in `.tools/`, because Spark 4.2 supports Java 17/21/25 and the system has Java 26 (unsupported). The system Java is untouched.
5. **`noop` sink** for job outputs (no winutils needed on Windows, and it measures compute rather than disk).
6. **Average (not marginal) CI**, as in Wiesner et al. 2021. Stated as a limitation.
7. Evaluation follows "Let's Wait Awhile" Scenario I, so our GB numbers can be compared with their published **4.3% (±2 h) / 7.4% (±8 h)**.

## Environment quick-start

```powershell
# from the project root
.venv\Scripts\activate
python scripts\fetch_carbon_data.py --start 2024-01-01 --end 2026-01-01   # resumable
python scripts\generate_tpcds.py --sf 1
```
`carbonsched.env.spark_session()` sets JAVA_HOME/SPARK_HOME automatically. The project path contains spaces ("Semester 5"), which breaks pyspark's `find-spark-home.cmd` unless SPARK_HOME is set.

Network note: on some networks (e.g. campus Wi-Fi with HTTPS inspection) API calls fail with `CERTIFICATE_VERIFY_FAILED`. Rerun the downloader on a normal network; it resumes. Do **not** disable certificate verification.
